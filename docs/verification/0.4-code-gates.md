### 7. Container

```sh

```

`docker compose config` exited 0. `docker compose up --build` built the image and started the
container. The web UI at `http://127.0.0.1:8081/` returned HTTP 200. `GET /api/v1/config`
returned `{"allow_register":false}`.

Admin port 8080 is bound to `127.0.0.1` only. A host request to `/` on that port returned 404.

and the named volume `sapie_sapie-data` survived. `docker compose down` removed the container and
network cleanly.

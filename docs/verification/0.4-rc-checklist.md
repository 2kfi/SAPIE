## Blocking rule

Any unchecked core-proof or launcher item blocks the tag. Security findings with no mitigation block
the tag unless the user explicitly records the risk as accepted. A failed gate with clean evidence is
useful; a patched game folder or a tag created to make a gate pass is not.

After the user reviews this draft and the evidence, the release owner may decide to tag. That decision
and any tag push are outside this document.
